# Ar-Rafi Ishraq Portfolio

A simple academic + engineering portfolio prepared for GitHub Pages.

## Publish with GitHub Pages

1. Create a new **public** GitHub repository named exactly:
   `ar-rafi-ishraq.github.io`

2. Upload everything in this folder to the repository root:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `assets/`

3. Commit the files.

4. In GitHub, open:
   **Settings → Pages**

5. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**

6. Save. After GitHub finishes deploying, the site should be available at:
   `https://ar-rafi-ishraq.github.io`
